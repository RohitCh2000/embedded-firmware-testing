# Embedded Firmware Testing
Automated firmware validation examples using Python and GoogleTest, covering sensor interfaces, motor-control functionality, watchdog and fault-recovery behavior, plus sensor-monitoring checks.

Personal project based on professional firmware verification experience (no employer code).

## Contents (planned)

- Python test automation and reporting
- Fault-injection and watchdog / recovery test cases
- HIL testing notes
